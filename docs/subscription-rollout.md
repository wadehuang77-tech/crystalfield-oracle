# 塔羅免費次數與月費方案上線 Runbook

塔羅帳號跨本站全部 7 個牌組共用 3 次免費完整占卜。每次成功解鎖一個牌陣計 1 次；單張牌也計 1 次。免費次數用完後，依牌陣選擇月費方案。月費有效期間，方案權益內的牌陣可無限次完整占卜：

| 方案 | 月費 | 牌陣權益 |
| --- | ---: | --- |
| 三張牌陣 | NT$600 | 所有單張與三張牌陣 |
| 前世因果 | NT$1,000 | 所有單張、三張與前世因果牌陣 |
| 全牌陣 | NT$1,500 | 所有 7 個牌組與全部牌陣，包含凱爾特十字、光行者神諭卡與光之訊息卡 |

上述月費方案每月自動續訂，會員可取消後續續訂。本期已付款權益保留至到期日。舊 `tarot_monthly_600` 訂閱保留原有全牌陣權益；新訂單只提供三種新方案。

目前不支援有效訂閱期間即時升級或切換方案；會員須取消後續續訂，待本期權益到期後再選擇新方案。

## 上線前準備

1. 確認 Worker secrets：`ECPAY_MERCHANT_ID`、`ECPAY_HASH_KEY`、`ECPAY_HASH_IV`、`JWT_SECRET`。
2. 確認綠界商店已開通信用卡定期定額。
3. 確認正式站 `/api/ecpay-webhook` 可由綠界連線。
4. 套用 `d1/migrations/024_tarot_free_readings.sql`，保留舊帳號已使用的免費次數。

## 必測流程

1. 同一帳號跨 7 個牌組完成三次牌陣後，第四次完整解讀需要足夠等級的月費方案。
2. 每次完成一個牌陣才計一次；同一 `reading_id` 的重試不可重複扣次。
3. NT$600 可不限次數使用全部單張及三張牌陣。
4. NT$1,000 另可使用偉特與埃及的前世因果牌陣。
5. NT$1,500 可使用本站全部牌組與所有牌陣。
6. Worker 直接 API 請求也依帳號免費餘額與付費等級驗證，不以瀏覽器狀態授權。
7. 付款成功及續扣回呼依實際方案金額驗證；未付款或付款失敗不開通權益。
8. 生命靈數、人類圖、印度占星的商品價格維持不變。

## 綠界週期設定

- `PeriodType = M`
- `Frequency = 1`
- `ExecTimes = 99`
- 方案金額依商品目錄分別為 NT$600、NT$1,000、NT$1,500。

取消訂閱只停止後續扣款，不會回收本期已付款權益。
