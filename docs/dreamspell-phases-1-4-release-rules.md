# Dreamspell Phase 1–4：自動正式上線規則

## 授權與適用範圍

2026-10-10，使用者確認：「開發完成後，自動部署正式網站並直接對外開放，不需人工驗收。」

本文件取代先前各階段中「完成後停止等待確認」「不得正式部署」「正式 migration 需另行授權」的未來發布限制。舊驗收結果仍是歷史事實，不因新授權改為 PASS。本次是更新部署與驗收規則，不代表尚未完成的功能已實作或上線。

完成全部開發、整合及自動檢查後，直接執行必要正式 D1 migration、Worker 部署、Pages 部署、會員及已完成付費報告功能開啟、中英文購買與閱讀開放、正式網站上線檢查，不再等待人工驗收或另外一次部署確認。

## 正式 AI 交付要求

- 使用既有 OpenAI 整合生成深度文字；KIN、五大神諭、波符僅使用已驗證 TypeScript 引擎，不由 AI 計算或補造。
- NT$499 十二篇、Pro 十五篇、雙人十二篇與雙人視覺／三視角／90 天計畫必須完成實際交付整合，不能只啟用付款開關。
- 完成且通過 Schema、語言及依據驗證的報告儲存 D1；再次閱讀取用同一份已儲存內容，不重新生成或重新扣款。
- 後端驗證會員、訂單、報告與出生資料所有權，並具備並行重複生成防護。
- 生成前成本預檢、請求 Token 上限、累計用量及成本限制必須實作；重試及並行請求不能繞過限制。超限阻止生成並記錄原因，不僅提供成本估算。
- 超時、供應商失敗、Schema 不符及超限回傳明確錯誤，保留可追蹤狀態；不得把 Mock 或不完整內容作為已完成付費報告。

## 自動發布門檻

以下全部 PASS，才可發布完整付費報告：

1. App／Worker TypeScript、ESLint、Production Build。
2. KIN 1–260、20 圖騰、13 音調、五大神諭與20波符驗證；包含獨立參考資料，不僅以同一公式產生預期值。
3. NT$499／699／899 前後端商品代碼及金額一致；NT$199與歷史699權益回歸。
4. 中英文 Schema／內容／路由及390、768、1440px版面、鍵盤與無障礙操作。
5. 匿名、未購買、其他會員、到期、撤權及退款記帳後權限隔離；訂單與報告所有權驗證。
6. Callback 簽章、商店、訂單、金額、付款狀態、冪等及偽造通知拒絕；SimulatePaid不授予正式權限，瀏覽器導回不授權。
7. 正式生成、儲存後讀取、不重複生成、成本上限、並行及錯誤處理；離線 Mock 結果不得宣稱為 Live AI 驗收。
8. 新 migration 本地套用與既有資料相容；正式 schema／ledger 唯讀核對、還原點及回滾目標記錄。
9. 既有塔羅付款、會員與其他命理系統基本回歸。

任一 FAIL／BLOCKED／NOT RUN 不得改稱 PASS，也不得只因授權而跳過門檻。自動流程修復並重跑；無法通過時回報實際阻礙，不要求使用者以人工驗收代替測試。

## 正式執行順序與保護

1. 記錄當前 deployment IDs、發布來源 hashes、D1狀態與 Time Travel 還原點。
2. 僅套用本次必要、已完成相容測試的 additive migration；不重跑既有 migration、不執行 Sandbox026、不刪除或重設既有資料。
3. 以可追溯的 Dreamspell 發布包部署 Worker／Pages，不將無關 dirty 工作樹修改混入正式發布。
4. 開啟會員與已完成報告的正式功能；Pro本地Mock開關與Sandbox維持關閉。
5. 自動執行正式 HTTPS、語言、路由、功能設定、匿名隔離及已授權報告閱讀／快取檢查，更新部署結果文件。
6. 上線異常停止新交易／生成並依記錄回滾；先核對在途付款，不能直接關閉 Callback 而遺失有效付款。保留新增資料表及交易，不以 D1 全庫還原覆蓋上線後真實付款。

本授權允許開放使用者自行購買與正式 AI 功能，不等於授權代理操作他人的信用卡、真實扣款或實際退款。自動技術檢查不假裝為官方實際交易驗收。沒有新增自動 commit／push 授權。
